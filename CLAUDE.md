# luminol-explore

Sandbox for Luminol, a C# GLua deobfuscator built on Loretta. Owner: Michael (GitHub `Michael-Tot`).

## Commit authorship (required for every AI agent)

Every commit must show **which agent made it and which human it was made for**:

- **Author name is `<Agent>@<Human>`; author email is always the human's.** The name shows which agent worked for whom; the email links the commit to the human's GitHub account. Before your first commit in a session, set it for this repo, e.g. `git -C <repo> config user.name "<Agent>@<Human>"` and `git -C <repo> config user.email "<human's email>"`, or pass `--author="<Agent>@<Human> <email>"` on each commit.
  - Michael: `Ariadne@Michael <mihailo.silni@gmail.com>`
  - Anyone else: ask them for their agent's name, their own name and their email before committing.
- **Never commit with the agent's own email or default identity** (e.g. `Claude <noreply@anthropic.com>`). If you aren't sure who you are working for, ask before committing.
- **Credit the agent in a trailer, not the author field**, e.g. `Co-Authored-By: Claude <noreply@anthropic.com>`, plus a session link if your tooling adds one.
- Applies to commits, merges and PR branches alike.
